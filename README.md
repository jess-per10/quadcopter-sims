# Quadcopter 6DOF Flight Simulation

A six-degrees-of-freedom quadcopter flight simulation built 
from scratch in Python, implementing full rigid body dynamics 
and numerical ODE integration.

## Physics implemented
- Translational dynamics (equation 21, Luukkonen 2011)
- Rotational dynamics (Newton-Euler equations)
- Euler kinematics (body frame → world frame conversion)
- Motor mixing matrix (motor speeds → forces and torques)
